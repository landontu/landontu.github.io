Selected work

Portfolio

WebHome

Draft copy WebHome is a Chromium MV3 new-tab extension that turns a blank tab into a configurable dashboard with search, widgets, wallpaper, and a keyboard-first slash-command palette. Its React/TypeScript architecture keeps layouts and settings in extension storage, while AI commands use short-lived, nonce-keyed chrome.storage.session records so prompts do not travel in provider URLs.

desmos-game

Draft copy ProjectKindaWorking is a five-level 3D puzzle platformer built entirely inside a Desmos 2D graph, including title/select/win states, keyboard movement, camera turns, one-way drops, and stateful doors. A Python generator emits the 310-item graph while offline validators cross-check the layered heightfield, movement, painter ordering, shading, camera staging, and solvability.

A public link for the current build is not available yet.

recall-AID

Draft copy recall-AID is a course-agnostic spaced-repetition workspace over a Markdown knowledge graph, with an FSRS-backed daily queue, map-first library, and keyboard-driven problem review. The current self-report MVP combines a Python/FastAPI core, SQLite review ledger, React/TypeScript frontend, and Tauri desktop shell while keeping course notes and card content human-readable and git-diffable.

Personal website

Draft copy This one-page personal site uses an interactive WebGL watercolor simulation as its background and carries that identity through its introduction, about, and portfolio sections. The watercolor has a separate exhibit where its composition can be explored directly.
